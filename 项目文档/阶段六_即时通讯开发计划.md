# 阶段六：即时通讯模块（WebSocket）开发计划

> **模块名称**: 实时通讯子系统 (IM Communication Module)
> **创建日期**: 2026-03-25
> **预计工期**: 1-2 天
> **技术方案**: Spring Boot WebSocket + uni-app 原生 SocketTask + Naive UI Web 端

---

## 1. 功能目标

实现 **订单维度** 的客户与设计师一对一即时通讯：

| 端 | 功能 | 优先级 |
|----|------|--------|
| C 端小程序 | 订单详情内嵌聊天窗口，发送文字/图片 | P0 |
| B 端 Web 后台 | 消息聚合列表（按订单分组），实时收发回复 | P0 |
| 后端 | WebSocket 长连接管理、消息持久化、离线消息查询 | P0 |

## 2. 技术架构

```
┌──────────────┐      WebSocket (ws://)      ┌──────────────────┐
│  小程序 C 端  │◄──────────────────────────►│                  │
│  uni.connectSocket                         │  Spring Boot     │
└──────────────┘                              │  WebSocketHandler│
                                              │                  │
┌──────────────┐      WebSocket (ws://)      │  - 鉴权 (JWT)    │
│  Web 后台 B 端│◄──────────────────────────►│  - 消息路由      │
│  native WebSocket                          │  - 持久化 MySQL  │
└──────────────┘                              └──────────────────┘
```

**消息流转**：发送方 → WebSocket Server → 查收方是否在线 → 在线则实时推送 / 不在线则仅落库等待拉取。

## 3. 数据库设计

### 3.1 聊天消息表 `ds_chat_message`

| 字段 | 类型 | 说明 |
|------|------|------|
| message_id | BIGINT PK AUTO_INCREMENT | 消息ID |
| order_id | BIGINT NOT NULL | 关联订单（聊天维度） |
| sender_type | VARCHAR(10) | 发送方类型: `client` / `admin` |
| sender_id | BIGINT | 发送人ID |
| content | TEXT | 消息内容 |
| msg_type | VARCHAR(20) DEFAULT 'text' | 消息类型: `text` / `image` |
| is_read | TINYINT(1) DEFAULT 0 | 是否已读（对方视角） |
| create_time | DATETIME | 发送时间 |

**索引**: `idx_order_id(order_id)`, `idx_sender(sender_type, sender_id)`

## 4. 后端开发清单

### 4.1 实体与 Mapper
- `com.designstudio.chat.domain.DsChatMessage`
- `com.designstudio.chat.mapper.DsChatMessageMapper`

### 4.2 WebSocket 配置与处理器
- `com.designstudio.common.config.WebSocketConfig` — 注册 WebSocket 端点 `/ws/chat`
- `com.designstudio.chat.websocket.ChatWebSocketHandler` — 核心消息处理器
  - `afterConnectionEstablished`: 解析 Token，注册在线会话
  - `handleTextMessage`: 解析收到的 JSON，路由到目标用户
  - `afterConnectionClosed`: 移除在线会话

### 4.3 在线会话管理
- `com.designstudio.chat.websocket.SessionManager` — ConcurrentHashMap 管理在线用户
  - key = `{userType}_{userId}`（如 `client_1`, `admin_2`）
  - value = WebSocketSession

### 4.4 REST API（历史消息查询）
- `com.designstudio.chat.controller.ChatController`
  - `GET /api/v1/app/chat/{orderId}` — C 端拉取某订单的聊天记录
  - `GET /api/v1/admin/chat/{orderId}` — B 端拉取某订单的聊天记录
  - `GET /api/v1/admin/chat/conversations` — B 端获取所有有未读消息的订单列表
  - `PUT /api/v1/admin/chat/{orderId}/read` — 标记某订单消息为已读

## 7. 消息协议（JSON）

```json
// 客户端 → 服务端（发送消息）
{
  "type": "SEND",
  "orderId": 1001,
  "content": "你好，请问进度如何？",
  "msgType": "text"
}

// 服务端 → 客户端（推送消息）
{
  "type": "NEW_MSG",
  "messageId": 12345,
  "orderId": 1001,
  "senderType": "admin",
  "senderId": 2,
  "senderName": "设计师小王",
  "content": "您好，正在打版中",
  "msgType": "text",
  "createTime": "2026-03-25 19:00:00"
}
```
