## 课题简介

随着"独立设计师品牌"的兴起，越来越多的设计师选择创建个人工作室，提供服装定制、手工皮具、数字插画等非标准化的个性化服务。然而，当前大多数独立工作室仍采用传统的作坊式管理模式，依赖微信群沟通、Excel表格排单，这种方式存在**信息孤岛严重、流程不透明、客户体验差**等突出问题。

市场上现有的ERP或订单管理系统，要么面向标准化电商（发货即完成），要么面向大型工厂（流水线生产），均无法满足独立工作室**"非标定制、强沟通、长周期"**的特殊生产特点。因此，亟需一套专门针对独立设计师工作室的生产流程管理系统。

本课题旨在设计并实现一个基于 **Spring Boot + 微信小程序** 的**低代码生产管理平台**，核心创新点包括：
1. **低代码业务扩展引擎**：通过元数据驱动的动态表单和可视化工作流编排，管理员无需编程知识即可配置新业务品类、定制参数表单和生产流程，实现"**流程即配置、表单即配置**"的零代码扩展能力。
2. **多维度生产效能分析与决策支持**：基于 ECharts 的可视化 Dashboard，从订单趋势、设计师效率、库存周转、客户画像等维度进行数据分析，将系统从"**数据记录工具**"升级为"**数据决策平台**"。
3. **全链路实时协同与进度可视化**：客户通过小程序实时追踪订单进度（时间轴展示），设计师通过拖拽看板高效管理多订单，双端支持 WebSocket 即时沟通，显著提升协作效率。

该系统的实现将显著提升独立设计师工作室的运营效率、数据决策能力和客户满意度，具有较强的实用价值和市场推广前景。

## 课题要求（包括所具备的条件）

### 1. 技术要求
- **后端开发**：熟练掌握 Java 编程语言，熟悉 Spring Boot 3.x 框架、MyBatis-Plus ORM、Spring Security 安全框架。
- **前端开发**：掌握 Vue 3 + Naive UI 构建后台管理系统；掌握 Uni-app (Vue 语法) 开发微信小程序。
- **数据库**：熟悉 MySQL 8.0 关系型数据库设计，了解 Redis 缓存机制。
- **其他技术**：了解 WebSocket 实时通讯原理；了解微信支付 API 接入流程；了解 RESTful API 设计规范。
- **开发工具**：Git 版本控制、Maven 项目管理、Postman/Apifox 接口测试。

### 2. 资源要求
- **开发环境**：个人电脑（Windows/Mac），配置 JDK 17、Node.js 18+、MySQL 8.0、Redis 7+。
- **开发工具**：IntelliJ IDEA / VS Code、HBuilderX (小程序开发)、微信开发者工具。
- **云服务** (可选)：阿里云/腾讯云服务器 (部署)、OSS 对象存储 (图片)、微信支付商户号 (支付功能)。

## 课题工作量要求

本课题要求在 **14 周** 内完成，主要任务如下：

1. **需求分析与系统设计 (W1-W2)**
   - 搜集调研独立设计师工作室生产管理的业务流程和痛点。
   - 完成系统需求规格说明书 (SRS)，定义 **10 大子系统、80+ 功能点**。
   - 完成数据库概念设计与逻辑设计，设计 29 张数据表。

2. **总体设计与模块划分 (W3-W4)**
   - 完成系统架构设计：分层架构、包结构规范、核心服务设计。
   - 模块划分：客户服务、内容展示、核心生产、供应链、支付交易、监控运维、**数据分析 Dashboard**、平台基础等子系统。
   - 完成 50+ 核心 API 接口设计。

3. **编码实现 (W5-W11)**
   - 后端：实现动态表单引擎、状态机引擎、订单管理、微信支付/退款、接口监控等核心功能。
   - 前端 (后台)：实现拖拽式生产看板、订单 360° 视图、BOM 管理、监控 Dashboard 等页面。
   - 前端 (小程序)：实现作品集展示、动态定制表单、进度时间轴、在线支付、即时沟通等功能。

4. **系统测试与调试 (W12-W13)**
   - 完成单元测试（核心 Service 覆盖率 > 60%）。
   - 完成接口测试与全流程端到端测试。
   - 进行性能优化与 Bug 修复。

5. **文档撰写与答辩准备 (W14)**
   - 撰写符合毕业要求的毕业设计说明书。
   - 准备答辩 PPT 和系统演示视频。
