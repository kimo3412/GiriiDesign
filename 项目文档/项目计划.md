## 阶段5: 小程序端开发计划

**目标**: 完成 C端（客户）所有功能，包括作品集展示、定制需求提交、订单进度追踪、微信支付

**预计周期**: W9-W10 (2周)

### 5.1 技术选型

- **开发框架**: Uni-app (Vue 3 版本)
- **打包目标**: 微信小程序 + H5 (可选)
- **UI组件**: uView UI 或 Uni-ui
- **图片存储**: 阿里云 OSS (复用 B端已有配置)

### 5.2 功能模块拆解

#### 模块一: 客户登录与档案 (FR-C1.x)

| 功能 | 后端 | 前端 | 优先级 |
| :--- | :--- | :--- | :--- |
| 微信一键登录 | 需新增: WxAuthController | 新建小程序登录页 | P0 |
| 获取微信 OpenID | 需新增: WxLoginDTO | 调用 wx.login | P0 |
| 个人档案管理 | 需新增: UserController | 个人中心页 | P1 |

**后端接口设计**:
```
POST /api/v1/auth/wx-login     # 微信登录
GET  /api/v1/users/me          # 获取当前用户信息
PUT  /api/v1/users/me          # 更新用户资料
```

#### 模块四: 定制需求提交 (FR-C6.x) - **核心**

| 功能 | 后端 | 前端 | 状态 |
| :--- | :--- | :--- | :--- |
| 选择定制品类 | 复用: CategoryController | 定制首页 | 已有接口 |
| 动态表单渲染 | 复用: CustomFieldController | **重点开发** | 已有接口 |
| 参考图片上传 | 需新增: OssController 小程序端点 | 文件上传组件 | 复用 |
| 提交意向 | 复用: RequestController (C端) | 提交页 | 需新增C端接口 |

**后端接口设计**:
```
GET    /api/v1/categories/active          # 获取激活品类
GET    /api/v1/categories/{id}/schema    # 获取动态表单Schema
POST   /api/v1/requests                  # 提交定制意向
POST   /api/v1/upload                    # 图片上传 (小程序版)
```

**前端难点**: 动态表单渲染
- 根据后端返回的 Schema 动态渲染表单项
- 支持字段类型: 文本、数字、下拉、单选、复选、图片上传
- 必填校验、格式校验

### 5.3 数据库补充

如以下表不存在，需创建:

```sql
-- 客户地址表
CREATE TABLE ds_user_address (
    address_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    receiver_name VARCHAR(50) NOT NULL,
    phone VARCHAR(20) NOT NULL,
    province VARCHAR(50),
    city VARCHAR(50),
    district VARCHAR(50),
    detail_address VARCHAR(200),
    is_default TINYINT DEFAULT 0,
    create_time DATETIME,
    del_flag TINYINT DEFAULT 0
);

-- 作品集表
CREATE TABLE ds_portfolio (
    portfolio_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    category_id BIGINT,
    images JSON,
    thumbnail_url VARCHAR(500),
    is_public TINYINT DEFAULT 1,
    create_time DATETIME,
    del_flag TINYINT DEFAULT 0
);

-- 支付记录表
CREATE TABLE ds_payment (
    payment_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_id BIGINT NOT NULL,
    payment_no VARCHAR(50) UNIQUE,
    amount DECIMAL(10,2) NOT NULL,
    payment_type TINYINT COMMENT '1:预付款 2:尾款',
    status TINYINT COMMENT '0:待支付 1:已支付 2:已退款',
    pay_time DATETIME,
    transaction_id VARCHAR(100),
    create_time DATETIME,
    del_flag TINYINT DEFAULT 0
);
```
