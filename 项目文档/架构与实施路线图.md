## 2. 技术选型与辩护 (Technology Defense)

> [!IMPORTANT]
> **答辩必备**：评委常问"为什么用这个技术"。以下是你的标准答案模板。

### 2.1 后端: Spring Boot 3.x
| 对比项 | Spring Boot | 其他方案 (如 Django, Node.js) |
| :--- | :--- | :--- |
| **语言生态** | Java 企业级首选，招聘市场需求量大 | Python/JS 更偏轻量级 |
| **框架成熟度** | 10年+，生态完善，文档丰富 | Django 成熟；Express 较轻 |
| **与论文匹配** | 计算机专业毕设主流选型 | 可能需额外解释选型理由 |
*   **辩护词**: "Spring Boot 是当前 Java 后端开发的事实标准，具有'约定优于配置'的特性，能快速搭建生产级应用。其与 MyBatis-Plus 的组合在国内企业中应用广泛。"

### 2.2 ORM: MyBatis-Plus
| 对比项 | MyBatis-Plus | JPA/Hibernate |
| :--- | :--- | :--- |
| **SQL 控制** | 直接写 SQL，灵活可控 | 自动生成 SQL，复杂查询难优化 |
| **学习曲线** | 低 | 高 (需理解 Criteria API) |
| **国内生态** | 非常流行，资料多 | 外企更常见 |
*   **辩护词**: "MyBatis-Plus 在 MyBatis 基础上增加了通用 CRUD 和代码生成能力，减少重复代码的同时保留了对 SQL 的完全控制，适合本项目对复杂 JOIN 查询和动态条件的需求。"

### 2.3 缓存: Redis
*   **用途**:
    1.  存储 JWT Token (实现分布式 Session / Token 黑名单)。
    2.  缓存字典数据、品类配置，减少数据库访问。
    3.  (可选) 聊天消息队列。
*   **辩护词**: "Redis 是业界最流行的键值缓存数据库，引入它能显著提升系统响应速度和并发能力。"

### 2.4 前端 (后台): Vue 3 + Naive UI
| 对比项 | Vue 3 | React |
| :--- | :--- | :--- |
| **学习曲线** | 平缓，文档友好 | 相对陡峭 |
| **生态 (后台UI)** | Naive UI / Arco Design Vue | Ant Design |
| **国内流行度** | 非常高 | 高 |
*   **辩护词**: "Vue 3 的 Composition API 提供了更灵活的逻辑复用方式。Naive UI 是新一代高颜值 Vue 3 组件库，设计感强、动画细腻，非常适合设计师类产品的后台界面。"

### 2.5 前端 (小程序): Uni-app
| 对比项 | Uni-app | 原生微信小程序 |
| :--- | :--- | :--- |
| **开发语法** | Vue 语法，复用前端技能 | WXML + WXS，需单独学习 |
| **跨平台** | 一套代码可编译到多端 (小程序/H5/App) | 仅限微信生态 |
*   **辩护词**: "Uni-app 使用 Vue 语法开发小程序，降低了全栈开发的认知负荷，并具备跨平台能力，为未来扩展到其他小程序平台或 App 预留了可能。"

### 6.2 JWT 鉴权过滤器骨架

```java
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    @Autowired
    private JwtUtils jwtUtils;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain) throws ServletException, IOException {
        String token = getTokenFromHeader(request);
        if (StringUtils.hasText(token) && jwtUtils.validateToken(token)) {
            // 从 Redis 检查 Token 是否有效 (黑名单机制)
            if (!redisTemplate.hasKey("blacklist:" + token)) {
                Long userId = jwtUtils.getUserIdFromToken(token);
                // 设置 SecurityContext
                UsernamePasswordAuthenticationToken auth = 
                    new UsernamePasswordAuthenticationToken(userId, null, Collections.emptyList());
                SecurityContextHolder.getContext().setAuthentication(auth);
            }
        }
        chain.doFilter(request, response);
    }
    
    private String getTokenFromHeader(HttpServletRequest request) {
        String header = request.getHeader("Authorization");
        if (StringUtils.hasText(header) && header.startsWith("Bearer ")) {
            return header.substring(7);
        }
        return null;
    }
}
```

### 6.3 意向转订单核心逻辑

```java
@Service
@Transactional
public class OrderServiceImpl implements IOrderService {

    @Autowired
    private DsOrderRequestMapper requestMapper;
    @Autowired
    private DsOrderMapper orderMapper;
    @Autowired
    private DsWorkflowMapper workflowMapper;
    @Autowired
    private DsWorkflowStepMapper stepMapper;

    @Override
    public Long convertRequestToOrder(Long requestId, OrderConvertDTO dto) {
        // 1. 查询意向
        DsOrderRequest request = requestMapper.selectById(requestId);
        if (request == null || request.getStatus() != 0) {
            throw new BusinessException("意向不存在或已处理");
        }

        // 2. 查询品类的初始工作流节点
        DsWorkflow workflow = workflowMapper.selectByCategoryId(request.getCategoryId());
        DsWorkflowStep firstStep = stepMapper.selectFirstStep(workflow.getWorkflowId());

        // 3. 创建订单
        DsOrder order = new DsOrder();
        order.setOrderSn(generateOrderSn()); // 雪花ID或时间戳
        order.setUserId(request.getUserId());
        order.setCategoryId(request.getCategoryId());
        order.setDesignerId(dto.getDesignerId());
        order.setCurrentStepId(firstStep.getStepId()); // 初始化为第一个节点
        order.setStatus(0); // 待支付
        order.setCustomDataSnapshot(request.getCustomData()); // 快照
        order.setTotalAmount(dto.getTotalAmount());
        order.setPrepayAmount(dto.getPrepayAmount());
        order.setExpectedDate(dto.getExpectedDate());
        orderMapper.insert(order);

        // 4. 更新意向状态
        request.setStatus(1); // 已转单
        request.setLinkedOrderId(order.getOrderId());
        requestMapper.updateById(request);

        return order.getOrderId();
    }
}
```

## 8. 生产级专项设计 (Production-Grade Design)

### 8.1 统一错误码规范 (Error Code Standard)

> [!IMPORTANT]
> **生产系统必须有统一的错误码**，不能只返回 "系统错误"。

#### 8.1.1 错误码格式
`XXYYY` - 5位数字
*   `XX`: 模块代码 (10-系统, 20-用户, 30-订单, 40-支付, 50-物料)
*   `YYY`: 具体错误序号

#### 8.1.2 核心错误码定义

| 错误码 | 模块 | 说明 |
| :--- | :--- | :--- |

### 8.2 监控与告警方案 (Monitoring & Alerting)

#### 8.2.1 日志规范

| 级别 | 使用场景 | 示例 |

#### 8.2.2 接口耗时监控 (AOP实现)

```java
@Aspect
@Component
public class ApiMetricsAspect {
    @Autowired
    private ApiMetricsService metricsService;

    @Around("@annotation(org.springframework.web.bind.annotation.RequestMapping) || " +
            "@annotation(org.springframework.web.bind.annotation.GetMapping) || " +
            "@annotation(org.springframework.web.bind.annotation.PostMapping)")
    public Object recordMetrics(ProceedingJoinPoint pjp) throws Throwable {
        long startTime = System.currentTimeMillis();
        String apiPath = getApiPath(pjp);
        boolean success = true;
        try {
            return pjp.proceed();
        } catch (Throwable t) {
            success = false;
            throw t;
        } finally {
            long costMs = System.currentTimeMillis() - startTime;
            metricsService.record(apiPath, costMs, success);
            // 慢接口告警
            if (costMs > 3000) {
                alertService.sendSlowApiAlert(apiPath, costMs);
            }
        }
    }
}
```

```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @Autowired
    private ExceptionLogService exceptionLogService;
    @Autowired
    private AlertService alertService;

    @ExceptionHandler(Exception.class)
    public R<?> handleException(Exception e, HttpServletRequest request) {
        // 1. 记录异常日志到数据库
        exceptionLogService.save(e, request);
        
        // 2. 发送告警 (企业微信/邮件)
        if (!(e instanceof BusinessException)) {
            alertService.sendExceptionAlert(e, request.getRequestURI());
        }
        
        // 3. 返回友好错误信息
        return R.fail(ErrorCode.SYSTEM_ERROR);
    }
}
```

### 8.4 微信支付接入指南 (WeChat Pay Integration)

#### 8.4.1 前置准备

1.  **申请微信支付商户号** (mch_id)。
2.  **关联小程序** (appid)。
3.  **配置API证书** (apiclient_key.pem, apiclient_cert.pem)。
4.  **设置支付授权目录** (小程序无需)。
5.  **配置回调通知地址** (如: `https://api.xxx.com/api/v1/payment/notify`)。

#### 8.4.2 支付流程

```
C端发起支付 -> 后端创建预支付单 (prepay_id) -> 返回签名参数给小程序
    -> 小程序调用 wx.requestPayment -> 用户完成支付
    -> 微信回调后端 notify 接口 -> 后端验签 + 更新订单状态
```

#### 8.4.3 核心代码 (使用 wechatpay-java SDK)

```java
@Service
public class WxPayService {
    private final WechatPayHttpClientBuilder httpClient;
    
    /**
     * 创建预支付单
     */
    public PrepayResponse createPrepay(DsPaymentRecord payment) {
        PrepayRequest request = new PrepayRequest();
        request.setAppid(wxPayConfig.getAppId());
        request.setMchid(wxPayConfig.getMchId());
        request.setDescription("订单支付-" + payment.getOrderSn());
        request.setOutTradeNo(payment.getPaymentNo());
        request.setNotifyUrl(wxPayConfig.getNotifyUrl());
        request.setAmount(new Amount().setTotal(payment.getAmount().multiply(new BigDecimal(100)).intValue()));
        
        // 调用微信API
        return jsapiService.prepay(request);
    }
    
    /**
     * 处理支付回调
     */
    @Transactional
    public void handleNotify(String requestBody, String signature, String serial, String nonce, String timestamp) {
        // 1. 验签 (SDK自动完成)
        Transaction transaction = notificationParser.parse(requestBody, signature, serial, nonce, timestamp, Transaction.class);
        
        // 2. 幂等校验
        DsPaymentRecord payment = paymentMapper.selectByPaymentNo(transaction.getOutTradeNo());
        if (payment.getStatus() == 1) {
            return; // 已处理，直接返回成功
        }
        
        // 3. 更新支付状态
        payment.setStatus(1);
        payment.setWxTransactionId(transaction.getTransactionId());
        payment.setPayTime(LocalDateTime.now());
        paymentMapper.updateById(payment);
        
        // 4. 更新订单状态
        orderService.onPaymentSuccess(payment.getOrderId(), payment.getPaymentType());
    }
}
```

#### 8.4.4 退款逻辑

```java
public void refund(Long orderId, BigDecimal refundAmount, String reason) {
    // 1. 校验可退金额
    DsOrder order = orderMapper.selectById(orderId);
    if (refundAmount.compareTo(order.getPaidAmount()) > 0) {
        throw new BusinessException(ErrorCode.REFUND_AMOUNT_EXCEED);
    }
    
    // 2. 创建退款记录
    DsRefundRecord refund = new DsRefundRecord();
    refund.setRefundNo(generateRefundNo());
    refund.setOrderId(orderId);
    refund.setRefundAmount(refundAmount);
    refund.setRefundReason(reason);
    refund.setStatus(0); // 处理中
    refundMapper.insert(refund);
    
    // 3. 调用微信退款API
    RefundRequest request = new RefundRequest();
    request.setOutTradeNo(order.getOrderSn());
    request.setOutRefundNo(refund.getRefundNo());
    request.setAmount(new RefundAmount()
        .setRefund(refundAmount.multiply(new BigDecimal(100)).intValue())
        .setTotal(order.getPaidAmount().multiply(new BigDecimal(100)).intValue())
        .setCurrency("CNY"));
    request.setReason(reason);
    
    Refund result = refundService.create(request);
    
    // 4. 更新退款状态 (也可等待异步回调)
    refund.setWxRefundId(result.getRefundId());
    refundMapper.updateById(refund);
}
```
