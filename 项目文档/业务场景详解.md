# 业务场景详解 - 独立设计师工作室定制行业

本文档详细说明本系统的目标行业、定制品类、生产流程及客户可见的透明化信息。

---

## 1. 目标行业与定制品类

### 1.1 行业定位

本系统面向 **手工艺定制行业** 中的独立设计师工作室，主要涵盖以下细分领域：

| 细分行业 | 典型品类 | 代表形态 |
| :--- | :--- | :--- |
| **服装高级定制** | 旗袍、汉服、婚纱、西装、Lolita、JK制服 | 个人裁缝铺、独立服装设计师工作室 |
| **手工皮具制作** | 手工皮包、皮带、皮夹、皮雕艺术品 | 皮具匠人工作室 |
| **首饰/饰品设计** | 手工银饰、珐琅饰品、编织手链、定制戒指 | 独立珠宝设计师 |
| **数字插画/设计** | 商业插画、IP形象设计、头像定制、海报设计 | 自由插画师、平面设计师 |
| **手工艺品定制** | 木雕、陶艺、刺绣、布艺玩偶 | 手工艺匠人工作室 |

### 1.2 设计师画像

| 角色类型 | 描述 |
| :--- | :--- |
| **独立服装设计师** | 拥有设计能力和制版/缝纫技能，承接客户的服装定制订单 |
| **皮具匠人** | 掌握皮料裁剪、缝制、皮雕等技艺，制作个性化皮具 |
| **珠宝/饰品设计师** | 设计并制作手工首饰，如银饰、珐琅、编织饰品 |
| **自由插画师** | 承接商业插画、IP设计、个人头像等数字设计需求 |
| **手工艺匠人** | 从事木雕、陶艺、刺绣等传统手工艺定制 |

## 2. 定制内容详解

### 2.1 服装定制 - 需采集的参数

| 参数类别 | 具体字段 |
| :--- | :--- |
| **身体尺寸** | 身高、体重、肩宽、胸围、腰围、臀围、袖长、衣长、裤长 |
| **款式偏好** | 领型（立领/翻领/圆领）、袖型（长袖/短袖/无袖）、版型（修身/宽松） |
| **面料选择** | 面料类型（棉/麻/丝绸/羊毛）、颜色、图案 |
| **特殊工艺** | 是否需要刺绣、盘扣、滚边、开叉等 |
| **参考图片** | 客户上传的款式参考图、灵感图 |

### 2.2 皮具定制 - 需采集的参数

| 参数类别 | 具体字段 |
| :--- | :--- |
| **产品类型** | 挎包/手拿包/钱包/皮带/卡包 |
| **皮料选择** | 皮料种类（牛皮/羊皮/植鞣革）、颜色、纹理 |
| **尺寸规格** | 长×宽×高、带长（皮带/挎包） |
| **五金配件** | 扣具颜色（金色/银色/古铜）、拉链类型 |
| **个性化定制** | 压印姓名/Logo、皮雕图案 |

### 2.3 数字插画 - 需采集的参数

| 参数类别 | 具体字段 |
| :--- | :--- |
| **用途场景** | 商业宣传/个人头像/IP形象/海报/包装 |
| **风格偏好** | 写实/扁平/日系/国风/赛博朋克 |
| **画面内容** | 人物数量、是否包含背景、主体元素描述 |
| **技术规格** | 尺寸（像素）、文件格式（PSD/PNG/AI）、分辨率 |
| **参考素材** | 客户上传的参考图、人物照片 |

## 3. 生产流程详解

### 3.1 服装定制生产流程

```
1. 需求确认  →  2. 量体裁衣  →  3. 打版/制图  →  4. 裁剪面料
      ↓
5. 缝制主体  →  6. 特殊工艺  →  7. 整烫定型  →  8. 质检包装
      ↓
9. 物流发货  →  10. 客户确认收货
```

| 节点 | 具体工作内容 | 预计耗时 |
| :--- | :--- | :--- |
| 需求确认 | 与客户沟通款式、面料、工艺细节 | 1-2天 |
| 量体 | 获取客户三围数据（到店/远程指导自测） | 1天 |
| 打版 | 根据尺寸绘制纸样/电脑制图 | 1-2天 |
| 裁剪 | 按纸样裁剪面料、里料、衬布 | 0.5天 |
| 缝制 | 拼接各部件、上拉链、装袖子等 | 3-5天 |
| 特殊工艺 | 刺绣、盘扣、手工滚边等 | 1-3天 |
| 整烫 | 熨烫定型、检查针脚 | 0.5天 |
| 质检包装 | 最终检查、挂吊牌、精美包装 | 0.5天 |

### 3.2 皮具定制生产流程

```
1. 需求确认  →  2. 设计出图  →  3. 皮料裁剪  →  4. 皮面处理
      ↓
5. 缝合成型  →  6. 五金安装  →  7. 边缘处理  →  8. 质检包装
```

| 节点 | 具体工作内容 |
| :--- | :--- |
| 需求确认 | 确认款式、皮料、颜色、五金、个性化内容 |
| 设计出图 | 绘制设计稿/效果图供客户确认 |
| 皮料裁剪 | 按版型裁剪皮料各部件 |
| 皮面处理 | 削薄边缘、打磨、上底色 |
| 缝合成型 | 手工缝线、粘合、组装各部件 |
| 五金安装 | 安装扣具、拉链、D环等 |
| 边缘处理 | 封边、打磨、上边油 |

### 3.3 插画定制生产流程

```
1. 需求确认  →  2. 草图绘制  →  3. 客户确认草图  →  4. 线稿精修
      ↓
5. 上色渲染  →  6. 细节调整  →  7. 终稿确认  →  8. 源文件交付
```

## 4. 客户可见的透明化信息

### 4.1 进度时间轴展示

客户在小程序/Web端可实时查看订单的生产进度，采用时间轴形式展示：

```
✅ 12月20日 10:30  需求已确认，即将进入生产
✅ 12月21日 14:00  纸样打版完成
✅ 12月22日 09:15  面料裁剪完成（附图）
🔵 当前阶段 →      缝制主体进行中（预计2天）
⬜ 待进行           特殊工艺（刺绣）
⬜ 待进行           整烫定型
⬜ 待进行           质检包装
⬜ 待进行           物流发货
```

### 4.2 每个节点可包含的信息

| 信息类型 | 说明 | 示例 |
| :--- | :--- | :--- |
| **节点名称** | 当前所处的生产阶段 | "缝制主体" |
| **完成时间** | 该阶段完成的具体时间 | "2024-12-22 15:30" |
| **进度图片** | 设计师上传的生产过程照片 | 裁剪后的面料照片、半成品照片 |
| **进度描述** | 设计师对当前进展的文字说明 | "袖子已完成，正在拼接前后片" |
| **预计完成** | 下一阶段或整体的预计完成时间 | "预计12月25日可发货" |

### 4.3 客户可主动获取的信息

| 信息 | 说明 |
| :--- | :--- |
| **订单基本信息** | 订单编号、下单时间、总价、已付/待付金额 |
| **定制参数回顾** | 当初提交的所有定制需求（尺寸、颜色、工艺等） |
| **当前进度** | 订单处于哪个生产阶段 |
| **历史进度** | 已完成的所有阶段及时间线 |
| **生产图片** | 设计师上传的过程图（裁剪、半成品、成品） |
| **物流信息** | 发货后的快递单号、物流轨迹 |
| **在线沟通记录** | 与设计师的聊天历史 |

## 5. 系统价值总结

| 痛点 | 传统方式 | 本系统解决方案 |
| :--- | :--- | :--- |
| 客户反复询问进度 | 微信一对一回复，占用设计师时间 | 小程序自助查看时间轴进度 |
| 不同品类采集信息不同 | 手工记录，容易遗漏关键参数 | 动态表单按品类自动生成必填项 |
| 生产流程不透明 | 客户只能等待最终交付 | 每个节点上传进度图+描述，全程可视 |
| 缺乏数据分析 | 凭经验估工期、定价格 | Dashboard展示设计师效率、成本、复购率 |
